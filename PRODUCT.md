# Product

## Register

product

## Users

People studying technical topics through self-paced lessons, and course authors
building those lessons in MDX. Learners read an explanation, predict behavior,
edit code, and inspect what actually happens without leaving the lesson.

## Product purpose

A reusable, tutor-style technical course template. Each lesson connects a
mechanism to an observable result and gives the learner a chance to practice.
The editor keeps code, output, errors, and checks in the same study surface.

## Brand personality

Use patient explanations that name the mechanism and the next action. Pair
editorial reading pages with familiar coding controls so readers can move
between an explanation and its example.

## Anti-references

Avoid turning a lesson into a full IDE, hiding essential feedback in browser
developer tools, or making decorative UI compete with the teaching material.

## Design principles

- Keep each explanation next to the example it explains.
- Let learners decide when to run code and reveal results.
- Distinguish code execution, passing checks, and understanding.
- Use the shared visual tokens and light/dark themes.

## Accessibility and inclusion

Keep controls keyboard accessible, label editor/output regions, communicate
state in text as well as color, and stack panels on narrow screens. Preserve
readable contrast and respect reduced-motion preferences.
